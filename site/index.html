# Bubble Tax landing page Static English landing page for GitHub Pages. No build step, external fonts, tracker, framework or embedded payment script. A short, monochrome product page uses one existing comic illustration and native app screenshots. Screenshots are actual macOS captures with isolated sample data; original color PNGs open in the image viewer. ## Preview From the repository root: ```sh python3 -m http.server 8765 --directory site --bind 127.0.0.1 ``` Open http://127.0.0.1:8765. Use any available port if occupied. ## Before publication Edit `site/config.js`: set `downloadUrl` to the actual Release asset, `githubUrl` to the public repository, and `coffeeUrl` to your Buy Me a Coffee page. `releaseLabel` should describe the actual version, architecture and signing status. Missing or invalid destinations stay disabled; there are no invented release or payment links. The current app/helper build targets Apple silicon and needs Python 3.9+ for collection (currently supplied by the developer's Command Line Tools). Validate prerequisites on a clean Mac before release; update download/install details accordingly. Signing/notarization or an explicit unsigned-beta installation guide must accompany the released artifact. ## GitHub Pages Push the repository to GitHub, use `main` (or update the workflow branch), and choose Settings → Pages → Source → GitHub Actions. `.github/workflows/pages.yml` deploys only `site/`. It runs on relevant pushes to main or manually from Actions. Deployment has not been performed locally. All asset paths are relative to support project Pages under `/repository-name/`. `assets/` contains seven native app captures and six existing persona illustrations. Capture source: `../../screenshots/landing-clean/`. No user account information is published. Keep demo captions when replacing screenshots with other demo captures. Screenshots are recaptured from the native app with `--hide-demo-badge`; isolated demo data and mutation guards remain active. Public captions identify the data as illustrative. The page is deliberately small: hero, six-screen viewer, a single Data note, download row and plain support link. Numbered sections, repeated slogans, three-column feature/persona grids and the FAQ were removed. Savings is the default screenshot. The larger hero capture stays clear of the decorative character; mobile omits the character. Feature navigation sits above a compact image/text row. ## Share metadata Open Graph and Twitter large-image metadata are in `index.html`, with a 1200×630 PNG at `assets/bubble-tax-og.png`. Regenerate from the existing comic asset and native typography with `swift scripts/render-og.swift` from the repository root. The canonical, OG URL and OG/Twitter image URLs use the current Sites origin. Update all of them together when moving to GitHub Pages or a custom domain; do not use localhost or relative image URLs for share metadata. The current Sites deployment is owner-private. Anonymous social preview crawlers may receive the sign-in page rather than the landing metadata; actual external unfurling requires anonymous access. No audience change was made when adding metadata. Product captures use richer isolated sample data. Transparent outer margins and the native popover arrow are cropped from the PNGs while preserving rounded corners. Additional dark-mode and single-service screenshots are provided separately. ## Appearance The page follows the system theme on first visit. Light/Dark switches persist locally. Product images use native light and dark captures; the hero combines a macOS desktop illustration with the native app capture. Its menu-bar quota uses the actual app title format and opens or closes the captured preview. Every tour screen and enlarged image follows the selected theme. The hero cycles five paid-plan sample quotas every 8 seconds. The flip matches the native 130ms fold and 170ms unfold, keeps the menu width fixed, and switches to a matching native capture. Reduced motion keeps the rotation without the flip; hidden tabs and enlarged screenshots pause the preview. ## Public preview [Download v0.1.0](https://github.com/bubble-tax/bubble-tax.github.io/releases/tag/v0.1.0). Apple silicon, macOS 14+, Python 3.9+. The ZIP contains the app and installation/release notes; SHA256SUMS.txt is a separate release asset. This preview is ad-hoc signed and not notarized.
