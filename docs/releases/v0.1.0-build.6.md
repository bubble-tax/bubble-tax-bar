# Bubble Tax v0.1.0 Preview · Build 6

## Claude window receipts · October 12, 2026

Compare how much weekly quota each observed 5-hour window consumes. Open **Quota history → Claude windows**.

- Paired Claude server readings are saved on each refresh, automatically every five minutes while the app runs.
- Each observed segment shows the 5-hour and weekly percentage-point changes side by side. Expand it for the two-meter timeline.
- A scatter plot and normalized weekly cost make different observed rates easier to compare. Rounded readings and reporting delays affect these rates; they are not a guaranteed conversion rule.
- Accounts, plans and weekly meters remain separate. Session/weekly resets, meter decreases and plan changes start a new segment. Collection gaps over 15 minutes and changes under 10 session percentage points are excluded from rate comparisons.
- Records stay on your Mac for 180 days. The view shows the latest 30 segments for the selected meter. Earlier unrecorded windows cannot be reconstructed. Claude-wide usage is included; activity cannot be attributed to a particular model or Claude Code alone.
- Existing settings, unused-quota history and savings records remain compatible.

## Install

Apple silicon · macOS 14+. Download the ZIP, extract it, quit the old app and replace **Bubble Tax.app** in Applications. Open it and look for **†** in your menu bar. Sign in to supported services and connect usage or local logs in Settings. Reconnect the Claude statusline bridge if you move the app.

The app is **Developer ID signed with Hardened Runtime and secure timestamps**, but **Apple notarization is not complete**. macOS may block first launch; follow [Apple's opening instructions](https://support.apple.com/guide/mac-help/open-a-mac-app-from-an-unknown-developer-mh40616/mac) if needed. Signing alone does not guarantee Gatekeeper acceptance.

Both provider and local-log collectors and their runtime are included. No external Python, developer tools or local server required. Supported providers: Claude, ChatGPT/Codex, Cursor, GitHub Copilot and Antigravity; Pi adds local coding-agent activity. Provider authentication is required. ChatGPT readings cover Codex quotas; missing readings remain unknown.
