# Bubble Tax v0.1.0 Preview · Build 11

- Use next: choose a task and compare available Claude and Codex quota, with personal and work accounts kept separate.
- Reserve: set aside weekly quota for named work with a deadline.
- Forecast: estimate weekly quota left at reset from observed usage windows and your planned hours per day.
- Patterns: inspect local request sizes, cache reuse and model mix.
- Plans: review paid plans using recorded quota history, reservations and peak demand.
- Includes the existing MacBook notch and menu bar modes. Existing settings and history are preserved.

Estimates need enough recent measurements. Reservations are local planning targets; they do not enforce provider limits or transfer quota between services.

To update, quit Bubble Tax and replace the app in Applications. Apple silicon · macOS 14+.

Developer ID signed and notarized by Apple. The notarization ticket is attached, and macOS Gatekeeper verification passed.
