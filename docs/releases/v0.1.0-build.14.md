# Bubble Tax v0.1.0 Preview · Build 14

- Allocation now keeps its feature tabs fixed above the content. Account group, task type and log source are labeled filters beneath the tabs.
- Switching sections returns the content to the top. Personal/work scope and the selected log source stay selected while browsing.
- Model labels now say “Model in logs” and “Models used.” These are provider models recorded in saved Claude Code / Codex logs, rather than a claim about on-device inference.

Apple silicon · macOS 14+. Developer ID signed and notarized by Apple, with the ticket attached.

Install: `brew install --cask bubble-tax/tap/bubble-tax`

Update: `brew update && brew upgrade --cask bubble-tax`. Quit Bubble Tax before updating, then reopen it.
