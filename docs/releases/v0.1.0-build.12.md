# Bubble Tax v0.1.0 Preview · Build 12

- Install with Homebrew: `brew install --cask bubble-tax/tap/bubble-tax`.
- Claude usage refresh now explicitly tries the signed-in Claude CLI when OAuth lookup cannot recover account identity.
- Prefer the current user-installed CLI over older Homebrew copies, restoring account-scoped 5-hour and weekly quota recording.
- The connected statusline bridge keeps local session quota pairs even while Bubble Tax is closed. Unverified sessions stay separate from account history and subscription recommendations.
- Quota history shows the latest paired reading and collection source, and prioritizes the current account.
- Existing settings and recorded account history are preserved. Missing past measurements cannot be reconstructed.

Apple silicon · macOS 14+. Developer ID signed and notarized by Apple, with the ticket attached.

Quit Bubble Tax before replacing the app. If you move the app after connecting the Claude statusline bridge, reconnect it in Settings. Homebrew installation uses Applications.
