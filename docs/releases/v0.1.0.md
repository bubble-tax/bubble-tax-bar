# Bubble Tax v0.1.0 Preview

The first public preview of Bubble Tax: a Mac menu-bar app for AI subscriptions you pay for and barely use.

## Self-contained app · Build 5 · October 10, 2026

The existing download now contains Build 5. Local Claude/Codex/Pi log collection and the optional Claude statusline bridge include their own runtime. No Python installation, Command Line Tools or local server is required to use the app.

- Native provider quota refresh continues to work independently of local logs.
- The packaged local collector runs after relocation, including paths with spaces, without an external Python interpreter.
- Existing Python-based Claude bridges can be upgraded by reconnecting in Settings. Their original display command and unrelated settings are preserved.
- Move the app to Applications before connecting the Claude bridge. Reconnect it if you later move the app.

Quit the existing app, download again and replace it in Applications. Apple silicon and macOS 14+ are still required; provider authentication is still needed. This preview remains ad-hoc signed and not notarized.

- Provider requests have bounded time and output, retain OAuth-first fallbacks, and do not store raw account identities.
- Existing Claude statusline snapshots remain readable without Python. Installing that optional bridge and reading local Claude/Codex/Pi activity still need Python.

Download again and replace the app to update. This remains an ad-hoc-signed, non-notarized preview.

## Download and install

Download **Bubble-Tax-0.1.0-macOS-arm64.zip** from the assets below. Extract it, move **Bubble Tax.app** to Applications, then open it. The app appears in the menu bar; it has no Dock window.

Requirements: **Apple silicon and macOS 14 or later**. Provider quota refresh needs existing service authentication. Python and Command Line Tools are not required: the native provider helper and local collector runtime are bundled with the app.

This preview is **ad-hoc signed, not Developer ID signed or notarized**. macOS may block first launch. If you choose to open it, follow [Apple's instructions for opening an app from an unknown developer](https://support.apple.com/guide/mac-help/open-a-mac-app-from-an-unknown-developer-mh40616/mac). No Intel build is included.

## Data and limits

Reads available quotas from existing provider sessions; local Claude/Codex logs are fallback activity. Availability varies by service and authentication. ChatGPT's displayed quota is Codex quota, not all ChatGPT features. Missing data stays unknown.

History, renewal schedules and recorded changes stay locally on your Mac. Public US list prices are estimates, not invoices. Current quota left is not expired waste. Work budgets are excluded from personal savings. Cancellation and downgrade are completed with the provider; records in Bubble Tax do not change your subscription.
