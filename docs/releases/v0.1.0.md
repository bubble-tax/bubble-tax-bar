# Bubble Tax v0.1.0 Preview · Build 13

- **Statusline change:** Claude quota fallback now displays its own concise five-hour and weekly quota line. It no longer runs or chains another statusline. Disconnect in Settings to restore the saved display.
- Existing Bubble Tax connections migrate automatically. Legacy bridge files are backed up and retired, preventing loops with other statusline tools.
- User-replaced statuslines are left alone until quota fallback is explicitly enabled again.
- Existing account history and local quota recordings are preserved.

Apple silicon · macOS 14+. Developer ID signed and notarized by Apple, with the ticket attached.

Install: `brew install --cask bubble-tax/tap/bubble-tax`

Update: `brew update && brew upgrade --cask bubble-tax`. Quit Bubble Tax before updating, then reopen it.
