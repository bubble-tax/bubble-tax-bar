# Bubble Tax v0.1.0 Preview · Build 8

- Claude and Codex now share window history, including weekly quota changes.
- See each interval’s model mix from saved code logs and input, output and cache tokens. Connect code logs in Settings to enable model context.
- Filter recorded windows by models seen in local activity.
- The main screen estimates the daily pattern needed to finish your weekly quota at your recent observed pace, including idle time.
- Shows when that pattern cannot fit before reset, when readings are insufficient, and when the weekly quota is already used.
- Existing settings and history are preserved.

To update, quit Bubble Tax and replace the app in Applications. Apple silicon · macOS 14+.

Developer ID signed; Apple notarization is not complete. If macOS blocks opening, see [Apple’s instructions](https://support.apple.com/guide/mac-help/open-a-mac-app-from-an-unknown-developer-mh40616/mac).
